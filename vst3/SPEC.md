# 刺さりを抑えるソフト VST3 版 仕様書（v2.1）

## 1. 目的

DAW での制作・ミックスで、女性ボーカルの「さ行」、ハイハット・シンバルの刺さり、歪みギターの耳障りな高音、鼻にかかった中域などの**耳に刺さる・耳障りな音を、出た瞬間に、その周波数だけ**下げる。

## 2. 前提（確認済みの決定事項）

| 項目 | 決定 |
|---|---|
| 使い方 | DAW での制作・ミックス（VST3 プラグイン） |
| 対象 OS | **Windows 11（x64）**。macOS / Linux 版も同じソースからビルドする（おまけ扱い） |
| 配布 | 自分だけで使う（JUCE の個人利用。配布・販売はしない） |
| インストール | zip を展開して手動でコピー |
| 追加機能 | ① 周りより突出した瞬間の検出 ② スペクトラム＋削った履歴 ③ 学習固定・A/B 比較・Undo/Redo ④ 解析範囲の拡張＋カスタムターゲット |

## 3. 動作環境・配布物

- 形式：VST3（64 bit）。プラグイン名 `SasariOsaeru`、メーカー名 `SasariOsaeru`、カテゴリ Fx / Dynamics / EQ
- 入出力：ステレオ→ステレオ、モノ→モノ
- サンプルレート：44.1〜192 kHz
- Windows 版は C++ ランタイムを静的リンクする（Visual C++ 再頒布パッケージのインストール不要）
- 配布物：`SasariOsaeru-Windows.zip` = `SasariOsaeru.vst3` フォルダ＋`インストール方法.txt`
- インストール先：`C:\Program Files\Common Files\VST3\`（フォルダごとコピー）
- 署名なし。Windows 11 の SmartScreen はプラグイン（DLL）には通常出ないが、zip を「ブロックの解除」する必要がある場合がある

## 4. 信号処理

### 4.1 方式
短時間フーリエ変換（STFT）。sqrt-Hann 窓、75 % オーバーラップ。帯域ごとにレベルを測り、帯域ごとに独立したコンプレッサーでゲインを下げ、周波数方向に滑らかに補間して適用する。

| 解析範囲 | 帯域 | フレーム長（48 kHz） | 遅延 |
|---|---|---|---|
| 標準 | 1.6〜16 kHz | 512（10.7 ms） | 10.7 ms |
| 拡張 | 400 Hz〜16 kHz | 1024（21.3 ms） | 21.3 ms |

- 帯域の細かさ：1/3 オクターブ（標準 10 本／拡張 16 本）、1/6 オクターブ（標準 20 本／拡張 32 本）
- 他のサンプルレートでも時間長がほぼ同じになるよう、フレーム長を 2 倍・4 倍にする
- 遅延は DAW に報告する（DAW が自動補正）。解析範囲を切り替えると遅延も変わり、DAW に通知する
- 処理中にメモリ確保をしない（全サイズを準備時に確保）

### 4.2 検出（どれだけ突出しているか）
帯域 b の瞬間レベル L[b] から、次の 2 つの「突出度」を求める。

- **普段比** oT = L[b] − 基準レベル[b]（基準は 4.3）
- **周囲比** oN = L[b] − 周囲平均[b]（自分を除く ±1 オクターブ内の帯域の平均、dB）

**SELECTIVITY（周囲比の割合）** s で混ぜる：o = (1 − s)·oT + s·oN
- 0 %：普段より大きくなったら反応（従来どおり）
- 100 %：その瞬間に周りの帯域より突出したら反応（soothe2 系の考え方。持続する共鳴にも効き、全体が明るいだけの場面には反応しない）
- 初期値 30 %

o に対象ターゲットのアタック／リリースで追従し（4.4）、しきい値と比べてゲインリダクションを決める。

### 4.3 基準レベル（REFERENCE）
| 方式 | 内容 |
|---|---|
| 固定推定 | 一般的な音楽のバランス（1/3 オクターブで全体の −15 dB、2 kHz 以上は −3 dB/oct） |
| オート（初期値） | 再生中の音から各帯域の普段のレベルを約 10 秒かけて追従（推定値から ±18 dB 以内） |
| 学習して固定 | **Learn** ボタンで 8 秒間の音を学習し、以後は固定。学習は常に 1/6 オクターブ 32 帯域で行い、プロジェクトに保存する。帯域の細かさ・解析範囲を変えても、1/3 オクターブは 2 帯域の合計として正確に換算して使う。未学習の帯域は固定推定を使う |

### 4.4 ターゲット
| ターゲット | 初期帯域 | アタック / リリース（基準） |
|---|---|---|
| 歪みギター | 2.5〜5 kHz | 4 ms / 120 ms |
| さ行 | 5〜10 kHz | 1 ms / 60 ms |
| ハイハット | 8〜16 kHz | 0.7 ms / 45 ms |
| **カスタム**（新規、初期 OFF） | 600〜1200 Hz（鼻にかかった声） | ATTACK / RELEASE ノブで指定（初期 5 ms / 100 ms） |

- 各ターゲット：ON/OFF、LOW / HIGH（400 Hz〜16 kHz）、PROCESSING（反応しやすさ：0 % = +30 dB、50 % = +10 dB、100 % = −10 dB）、INTENSITY（レシオ 1:1〜20:1）、**チャンネル**（v2.1）
- 4 つとも同時に ON にでき、それぞれ独立に調整できる（ボタンは編集対象の選択）
- 帯域の中心が LOW〜HIGH に入る帯域を担当。同じ信号（Mid / Side）で重なった帯域は PROCESSING が高い方

### 4.4.1 ターゲットごとのチャンネル（v2.1）
内部では常に Mid（中央）と Side（左右の広がり）に分けて処理し、最後に L/R へ戻す（変換だけでは音は変わらない）。

| チャンネル | 検出する信号 | 下げる信号 | 用途の例 |
|---|---|---|---|
| ステレオ（初期値） | L と R の大きい方 | Mid と Side を同じ量（＝左右同じ、定位は変わらない） | 一般 |
| Mid | Mid | Mid だけ | 中央のリードボーカルのさ行 |
| Side | Side | Side だけ | 左右に広がったシンバル、ダブリングのギター |

- Mid と Side で担当ターゲットを別々に決めるので、例えば「さ行＝Mid」「ハイハット＝Side」なら重なる帯域でも両方が同時に働く
- 基準レベル（固定推定・オート・学習）も L/R、Mid、Side ごとに持つ（Side の固定推定は L/R より 12 dB 低い）
- SHARPNESS がアタック／リリースを ×2〜×0.5、ニー幅を 12〜0 dB にする。高い帯域ほど速く反応（2 kHz で ×1.4、16 kHz で ×0.5、低域は ×1.5 まで）
- 解析範囲外の帯域を指定したターゲットは、画面に「解析範囲外」と表示する

### 4.5 その他の処理
- **RANGE**：1 帯域あたりの最大リダクション 0〜24 dB（初期 12 dB）
- **MIX**：ドライ／ウェット 0〜100 %（遅延補正済み、0 % で入力と完全一致）
- **OUTPUT**：−12〜+6 dB
- **高域シェルフ（常時）**：周波数 2〜16 kHz、ゲイン −18〜0 dB
- **モニター**：Normal／Filter（選択中ターゲットの帯域だけ）／Delta（削った成分だけ）
- **バイパス**：遅延を保ったまま素通し

## 5. 画面（日本語、拡大縮小可）

設計サイズ 1000×740、70〜160 % で縦横比を保って拡大縮小（Windows の高 DPI 表示にも対応）。

| 場所 | 内容 |
|---|---|
| 上段 | タイトル、プリセット、**A / B / A→B**、**元に戻す / やり直す**、Normal・Filter・Delta |
| 左 | 選択中ターゲットの効き方のカーブ |
| 右上 | **スペクトラム**（入力＝灰、出力＝白、100 Hz〜20 kHz）。帯域ごとの担当色、選択中ターゲットの枠、**削った量（赤）**、シェルフ曲線、解析範囲外の減光 |
| 右中 | 帯域ごとの突出度バーとしきい値（白線） |
| 中段 | **削った履歴**（横＝直近 8 秒、縦＝周波数、色の濃さ＝リダクション量） |
| ターゲット | 4 つのターゲットボタン（ON/OFF とチャンネルを表示）、ON/OFF、**チャンネル（ステレオ / Mid / Side）**、LOW・HIGH・PROCESSING・INTENSITY（カスタムは ATTACK・RELEASE も）、説明文 |
| 共通 | SHARPNESS・MIX・RANGE・OUTPUT・SELECTIVITY、高域シェルフ、基準レベル＋**Learn**＋状態、帯域の細かさ、解析範囲 |

- ノブ：上下ドラッグ、ダブルクリックで初期値
- プリセット欄：今のプリセット名を表示する（画面やプロジェクトを開き直しても同じ）。音の設定がそのプリセットから変わると（ノブ・元に戻す・A/B・オートメーション）「変更あり：プリセット名」と表示し、同じプリセットを選び直すと適用し直す。編集中のターゲットとモニター（Normal／Filter／Delta）の切り替えは変更に数えない
- 元に戻す／やり直す：ノブ・ボタン・選択の変更を 1 操作ずつ
- A/B：全パラメータの 2 セット。切替時に今の設定を保存、A→B で今の設定をもう一方へコピー。プロジェクトに保存

## 9. 対象外・制限
- 声の音素を AI で判別する検出（Waves Sibilance / smart:deess 方式）は対象外
- 外部サイドチェーン入力は対象外
- 実機の DAW での確認は、利用者の Windows 11 環境で行う（開発環境には DAW がないため）
