# 刺さりを抑えるソフト VST3 版 2.1（SasariOsaeru）

女性ボーカルの「さ行」、ハイハットの刺さり、歪みギターの耳障りな高音、鼻にかかった中域などを、**出た瞬間に、その周波数だけ**下げる VST3 プラグインです（DAW での制作・ミックス用、Windows 11 想定）。
詳しい仕様は [SPEC.md](SPEC.md) を参照してください。

## インストール（Windows 11）

1. GitHub の Actions →「VST3 (SasariOsaeru)」→ 最新の実行 → Artifacts の **SasariOsaeru-VST3-Windows** をダウンロード
2. zip を右クリック →「プロパティ」→「許可する」にチェック（ある場合）
3. 展開した `SasariOsaeru.vst3` フォルダを、フォルダごと `C:\Program Files\Common Files\VST3\` にコピー
4. DAW でプラグインを再スキャン（手順は zip 内の `インストール方法.txt`）

Visual C++ ランタイムは内蔵しているため追加のインストールは不要です。macOS / Linux 版も同じ Artifacts にあります。

## できること

| 機能 | 内容 |
|---|---|
| 4 つのターゲット | 歪みギター／さ行／ハイハット／**カスタム**（帯域・ATTACK・RELEASE を自由に）。同時に使え、それぞれ個別に調整 |
| **ターゲットごとのチャンネル** | ステレオ／Mid（中央のボーカル）／Side（左右のシンバル）。「さ行＝Mid、ハイハット＝Side」なら同じ帯域でも両方が別々に働く |
| ピンポイント検出 | 1/3 または 1/6 オクターブの帯域ごとに独立して検出・抑制 |
| **SELECTIVITY** | 0 %＝普段より大きくなったら反応、100 %＝その瞬間に周りの帯域より突出したら反応（持続する共鳴にも効き、全体が明るいだけでは反応しない） |
| 基準レベル | 固定の推定値／オート（曲に追従）／**学習して固定（Learn）** |
| 解析範囲 | 1.6〜16 kHz（遅延 10.7 ms）／**400 Hz〜16 kHz（遅延 21.3 ms）** |
| 先読み | 遅延を DAW に報告して自動補正（さ行の出だしから下がる） |
| モニター | Normal／Filter（対象帯域だけ）／Delta（削った成分だけ） |
| MIX / RANGE | 本物のドライ/ウェット、1 帯域あたりの最大リダクション |
| 表示 | **入出力スペクトラム＋削った量**、帯域ごとの突出度としきい値、**削った履歴（8 秒）**、効き方のカーブ |
| 操作 | **A/B 比較**、**元に戻す／やり直す**、プリセット 8 種、画面の拡大縮小（70〜160 %） |

## 使い方のコツ

1. プリセットで近いものを選ぶ
2. 刺さる音のターゲットを選び、**Filter** で LOW / HIGH を刺さる音がよく聞こえる範囲に合わせる
3. **Normal** に戻し、PROCESSING を「刺さる瞬間だけ赤が出る」くらいまで上げる
4. **Delta** で削った成分を聴き、言葉や楽器の芯まで削れていないか確認する
5. 曲全体の明るさは残して共鳴だけ取りたいときは SELECTIVITY を上げる
6. ボーカルのさ行は「Mid」、左右に広がったシンバルは「Side」にすると、互いに影響せずに抑えられる
7. 曲ごとに効き方を固定したいときは、サビなど代表的な部分を再生しながら **Learn**

## テスト

| テスト | 内容 |
|---|---|
| `EngineTests`（87 項目、JUCE なし） | 透過性と遅延（44.1〜192 kHz、両解析範囲）、帯域ごとの低減、Range、Mix、Delta、Filter、ターゲットごとのチャンネル（Mid のさ行と Side のシンバルを同じ帯域で同時に低減、ステレオは左右同量で定位を保つ）、オート、SELECTIVITY（持続する共鳴は下げる／全体の明るさは下げない）、拡張範囲とカスタム、学習と復元、スペクトラム表示値、A/B、**処理中のメモリ確保ゼロ** |
| `ProcessorTests`（20 項目） | 元に戻す／やり直す、A/B、Learn と学習結果のプロジェクト保存・復元、プリセット（チャンネル設定を含む）、遅延の更新、画面（開く・拡大縮小・大きさの記憶） |
| `PluginHostTest`（21 項目） | 完成した .vst3 を DAW と同じ方法で読み込み、パラメータ・遅延（切替時の DAW への通知を含む）・音声処理・プリセット・状態を確認 |
| GitHub Actions | Windows / macOS / Linux でビルド・上記テスト・pluginval（strictness 5） |

## ビルド

```sh
cmake -S vst3 -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release        # Linux では xvfb-run -a ctest ...
```

JUCE 8.0.12 は自動で取得されます。個人利用の前提です（配布・販売する場合は JUCE のライセンス条件を確認してください）。
