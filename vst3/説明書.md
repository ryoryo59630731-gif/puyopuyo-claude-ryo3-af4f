# 刺さりを抑えるソフト 説明書（SasariOsaeru 2.1）

女性ボーカルの「さ行」、ハイハットの「チッ」、歪みギターのジャリジャリなど、**耳に刺さる音を、出た瞬間に、その周波数だけ**下げるプラグインです。
このページでは、画面のボタン・つまみ・表示を 1 つずつ説明します。インストール方法は `インストール方法.txt`、仕様の詳細は `SPEC.md` を見てください。

---

## 0. しくみをひとことで

1. 音を細かい周波数の帯（帯域）に分けて、帯域ごとに「今どれだけ大きいか」を測ります。
2. それを **基準レベル**（その帯域の普段の大きさ）や、周りの帯域と比べて、「どれだけ突き出ているか（突出度）」を出します。
3. 突出度が **しきい値** を超えた帯域だけを、コンプレッサーのように下げます。しきい値は「ターゲットごとの PROCESSING」＋「全体の THRESHOLD」＋「帯域ごとの補正（帯域ごとモードのとき）」で決まります。下げる量の上限は **RANGE** です。
4. 削った量を **MIX** で元の音と混ぜ、**OUTPUT** で全体の音量を整えて出力します。

```
今のレベル ─┬─ 基準レベルとの差 ──┐
           └─ 周りの帯域との差 ──┴─ SELECTIVITY で混ぜる ＝ 突出度
しきい値 ＝ PROCESSING の値 ＋ THRESHOLD ＋ 帯域ごとの補正（帯域ごとモードのとき）
突出度 − しきい値 ＝ 超えた分
超えた分 × INTENSITY（比率）＝ 下げたい量 → RANGE で頭打ち → MIX で混ぜる → OUTPUT
```

## 1. 画面の配置


## 2. 上段

### プリセット
左の欄をクリックすると一覧が開きます。

**標準プリセット（8 種）**

| 名前 | 内容 |
|---|---|
| Standard (all three targets) | 初期設定。歪みギター・さ行・ハイハットの 3 つが ON |
| Female vocal sibilance | 女性ボーカルのさ行向け（5.5〜11 kHz を強めに、ギターは OFF） |
| Hi-hats and cymbals | ハイハット・シンバル向け（7〜16 kHz を強めに） |
| Distorted guitar | 歪みギター向け（2〜6 kHz） |
| Gentle | 3 つとも控えめ |
| Long listening (+ shelf) | 長時間聴いても疲れにくいように、高域シェルフ（9 kHz、−3 dB）も ON |
| Vocal on Mid, cymbals on Side | さ行は中央（Mid）だけ、ハイハットは左右の広がり（Side）だけで抑える |
| Nasal mids (extended range) | 鼻にかかった声（600〜1200 Hz）。解析範囲を 400 Hz〜 にする |

標準プリセットは「解析範囲」「検出の細かさ」「基準レベル」を変えません（Nasal mids だけは解析範囲を 400 Hz〜 にします）。

**自作プリセット**
- **保存**：一覧の「今の設定を保存…」→ 名前を入れて「保存」（Enter でも保存、Esc で取り消し）。同じ名前があるときは、その場で「上書きします」と表示されます。
- **読み込み**：一覧の「自作プリセット」の下から選びます。
- **削除**：自作プリセットを選んでいるときに一覧に出る「『名前』を削除…」→「削除」。ファイルを消すので元に戻せません。
- **保存先**：`%APPDATA%\SasariOsaeru\Presets`（エクスプローラーのアドレス欄に貼り付けると開けます）。1 プリセット 1 ファイル（`.sasaripreset`）で、どのプロジェクトからも使えます。ファイルをコピーすれば別の PC にも持っていけます。
- **保存される内容**：モニター（Normal／Filter／Delta）以外のすべての設定。Learn で覚えた基準レベルそのものはプロジェクトごとのデータなので、プリセットには入りません（「学習して固定」のプリセットを別の曲で使うときは、もう一度 Learn してください）。
- 名前に `\ / : * ? " < > |` などファイル名に使えない文字があると、それを除いた名前で保存します。

**「変更あり：」の表示**：プリセットを選んだあとに音の設定を変えると（つまみ・元に戻す・A/B・オートメーション）、欄に「変更あり：プリセット名」と出ます。同じプリセットを選び直すと、プリセットの設定に戻ります。編集するターゲットの切り替えと、Normal／Filter／Delta の切り替えは「変更」に数えません。

### A ／ B ／ A→B（設定の聴き比べ）
- 設定を 2 組（A と B）持てます。光っている方が今使っている設定です。
- **A**・**B**：押すと、今の設定をそのスロットに残して、もう一方に切り替えます。B を初めて押したときは、A と同じ設定から始まります。
- **A→B**（B を使っているときは **B→A**）：今の設定を、もう一方のスロットにコピーします。気に入った設定を残したまま別案を試したいときに使います。
- A・B の両方の設定がプロジェクトに保存されます。

### 元に戻す ／ やり直す
つまみ・ボタン・プリセット選択などの変更を、1 操作ずつ戻したり進めたりします。

### Normal ／ Filter ／ Delta（モニター）
| ボタン | 聞こえる音 | 使いどころ |
|---|---|---|
| Normal | 処理した音（通常） | ふだんはここ |
| Filter | 選んでいるターゲットの帯域だけ | LOW / HIGH を「刺さる音がよく聞こえる範囲」に合わせる |
| Delta | 削った成分だけ | 「サ」「チッ」だけが聞こえれば適切。言葉や楽器の芯まで聞こえたら削りすぎ |

## 3. 表示

### 効き方のカーブ（左上）
選んでいるターゲットの「入力（横軸）→ 出力（縦軸）」のグラフです。横軸は「基準レベル（または周りの帯域）からどれだけ大きいか」です。右上の「6.0:1 +8 dB」は、**比率（INTENSITY）** と **しきい値**（基準より何 dB 上で下げ始めるか、PROCESSING で決まる）です。

### スペクトラム（右上、「スペクトラム」ボタン）
- 灰の線＝入力、白の線＝出力、赤＝削った量。
- 色の帯＝その帯域を担当しているターゲット（Mid と Side で担当が違うときは、上半分＝Side／下半分＝Mid）。
- 枠＝今選んでいるターゲットの範囲。暗い部分＝解析範囲の外（処理しない）。
- 右上の「最大リダクション」＝今いちばん下げている帯域の量。

### 基準レベル表示（右上、「基準レベル」ボタン）
基準レベルが **どう決まり、どう変わったか** を帯域ごとに見る画面です。
- **棒**＝今のレベル（赤くなっている帯域は今削っている）
- **黄の線**＝今使っている基準レベル（普段の大きさ）
- **点線**＝固定の推定値（基準レベルの出発点）
- **白線**＝しきい値（黄の線＋そのターゲットのしきい値）。棒が白線を超えると削られます。SELECTIVITY が 0 % のときはぴったり、それ以外は目安です
- 帯域ごとモードでは、白線に丸い取っ手と補正値（＋は緑、−は赤）が付き、ドラッグで調整できます（6 章）。見出しの「補正をリセット」で全部 0 dB に戻ります
- 左上：今の基準レベルの方式（固定の推定値／オート／学習して固定）。右上：表示している信号（選んでいるターゲットのチャンネルに合わせて L/R・Mid・Side）。
- 2 行目：選んでいるターゲットの帯域について、「基準は推定値より平均何 dB 動いたか（最小〜最大）」と「今のレベルが基準より平均何 dB 大きいか」。

**読み方の例**：オートで曲を再生すると、黄の線が点線から離れていきます。Learn すると、その曲の普段のレベルで黄の線が固定されます。棒が黄の線よりずっと上に出て赤くなっている帯域が、今削られているところです。

### 突出度（バー）としきい値（白線）（スペクトラムの下）
帯域ごとの「どれだけ突き出ているか」（バー）と、そのターゲットのしきい値（白線）です。バーが白線を超えて色が付いた帯域が削られます。

### 削った履歴（中段）
直近 8 秒間に、どの周波数（縦）を、いつ（横、右が今）、どれだけ（色の濃さ）削ったかです。

## 4. ターゲット（抑えたい音の種類）

| ターゲット | 初期の帯域 | 反応の速さ | 向いている音 |
|---|---|---|---|
| 歪みギター | 2.5〜5 kHz | ゆっくり（アタック 4 ms／リリース 120 ms） | 持続するジャリジャリ |
| さ行 | 5〜10 kHz | 速い（1 ms／60 ms） | 「サ・シ・ス・セ・ソ・ツ」（女性 5.5〜11 kHz、男性 4〜8 kHz が目安） |
| ハイハット | 8〜16 kHz | とても速い（0.7 ms／45 ms） | 「チッ」「シャーン」 |
| カスタム | 600〜1200 Hz（初期は OFF） | ATTACK／RELEASE で自由に | 鼻にかかった声など |

- **4 つのボタン**：押したターゲットが下のつまみで編集する対象になります（ON/OFF ではありません）。ボタンには ON/OFF とチャンネル（/ Mid、/ Side）が表示されます。4 つとも同時に使えます。
- **「○○」を抑える（右上のスイッチ）**：選んでいるターゲットの **ON／OFF**。OFF にすると、そのターゲットは何もしません。
- **チャンネル［ステレオ］［Mid］［Side］**：そのターゲットが **どの音を見て、どこを下げるか**。

| チャンネル | 見る音 | 下げる音 | 例 |
|---|---|---|---|
| ステレオ（初期値） | 左右の大きい方 | 左右とも同じ量（定位は変わらない） | 一般 |
| Mid | 中央の音 | 中央だけ | 中央のリードボーカルのさ行 |
| Side | 左右の広がり | 広がりだけ | 左右に広がったシンバル、ダブリングのギター |

「さ行＝Mid、ハイハット＝Side」にすると、同じ帯域でもボーカルとシンバルを別々に抑えられます。

- **LOW / HIGH**：担当する周波数の範囲（400 Hz〜16 kHz）。Filter で聴きながら合わせると楽です。
- **PROCESSING**（反応しやすさ＝しきい値）：上げるほど小さな突出でも反応します。0 %＝基準より +30 dB（ほぼ反応しない）、50 %＝+10 dB、100 %＝−10 dB（基準より小さくても反応）。つまみの表示「55 % (+8 dB)」の（ ）内がしきい値です。カーブ表示の「+8 dB」には、これに THRESHOLD を足した値が出ます。
- **INTENSITY**（効きの強さ＝比率）：しきい値を超えた分をどれだけ強く下げるか。0 %＝1:1（下げない）、50 %＝約 4.5:1、100 %＝20:1。
- **ATTACK / RELEASE**（カスタムだけ）：反応の速さ（0.5〜50 ms）と戻りの速さ（10〜500 ms）。
- 「⚠ この帯域は解析範囲の外です」と出たら、「解析範囲」を 400 Hz〜 にしてください。

## 5. 共通のつまみ

| つまみ | 範囲（初期値） | 説明 |
|---|---|---|
| SHARPNESS | 0〜100 %（50） | 効き方のキレ。上げると反応が速く（×0.5）、しきい値の前後の変化が急に（ニー 0 dB）。下げるとゆっくり（×2）・なだらか（ニー 12 dB） |
| MIX | 0〜100 %（100） | 処理した音と元の音の割合。0 % で元の音と完全に同じ。50 % なら下げ量はおよそ半分の効き |
| RANGE | 0〜24 dB（12） | **1 つの帯域を最大何 dB まで下げるか**。INTENSITY や PROCESSING を上げても、ここより深くは下がりません |
| OUTPUT | −12〜+6 dB（0） | 最後の音量 |
| SELECTIVITY | 0〜100 %（30） | 何と比べて「突き出ている」と判断するか（下の説明） |
| THRESHOLD | −20〜+20 dB（0） | **全ターゲットのしきい値をまとめて上下**する。＋で効きにくく、−で効きやすく。PROCESSING を 4 つ別々に回さずに全体の効き始めを調整できる |

### しきい値の「一括」と「帯域ごと」
THRESHOLD の上にある 2 つのボタンで切り替えます。

| モード | しきい値 | 使いどころ |
|---|---|---|
| 一括（初期値） | 各ターゲットの PROCESSING ＋ THRESHOLD。同じターゲットの帯域はみな同じしきい値 | ふだん使い。シンプル |
| 帯域ごと | 上に加えて、帯域ごとの補正（−20〜+20 dB）を足す | 特定の共鳴だけ早めに抑えたい／この帯域は削りたくない、など細かく決めたいとき |

**帯域ごとの補正のしかた**
1. ［帯域ごと］を押すと、右上が自動で「基準レベル」表示になります。
2. 白線（しきい値）の帯域を上下にドラッグします。**上げる＝その帯域は効きにくく、下げる＝効きやすく**。0.5 dB 刻みです。
3. ダブルクリックでその帯域を 0 dB に、見出しの「補正をリセット」で全帯域を 0 dB に戻します。
4. ドラッグできるのは、ターゲットが担当している帯域だけです。補正は 1/6 オクターブ（400 Hz〜16 kHz の 32 帯域）単位で保存され、検出の細かさが 1/3 オクターブのときは 2 帯域ぶんをまとめて動かします。

- ［一括］に戻すと補正は効かなくなりますが、値は消えずに残ります。［帯域ごと］に戻せば元どおりです。
- 補正は A/B・元に戻す・自作プリセット・プロジェクトに保存されます。DAW のオートメーション一覧には出ません（32 個あると一覧が埋まるため）。
- 標準プリセットを選ぶと、THRESHOLD は 0 dB、モードは「一括」に戻ります（補正の値は残ります）。

### SELECTIVITY（選択性）
- **0 %**：その帯域の **普段のレベル（基準レベル）** より大きくなったら反応します。曲全体が明るくなったときも反応します。
- **100 %**：その瞬間に **周りの帯域（上下 1 オクターブ）より** 突き出たら反応します。ずっと鳴り続ける共鳴にも効き、曲全体が明るいだけの場面では反応しません。
- 間の値は 2 つを混ぜます（30 %＝普段比 7 割＋周囲比 3 割）。「全体が明るいところまで削られる」と感じたら上げ、「刺さる瞬間を取り逃がす」と感じたら下げます。

### どれだけ下がるか（RANGE・INTENSITY・MIX の関係）
- 下がる量は「しきい値を超えた分 ×（1 − 1/比率）」で、**RANGE で頭打ち**、そのあと **MIX** で元の音と混ぜます。
- 例：RANGE 12 dB のときは、どれだけ強くしても 1 帯域あたり 12 dB まで（表示の最大リダクションはおよそ −11〜−12 dB）。**−17 dB くらいまで下げたいときは RANGE を 18 dB にします**（テスト信号での実測：RANGE 12 dB→−11.1 dB、6 dB→−5.5 dB）。
- MIX を下げると、下げ量は全体に浅くなります（MIX 50 % で RANGE 12 dB の帯域は約 −6 dB）。

## 6. 高域シェルフ

スイッチで ON/OFF。刺さりとは関係なく、**常に** 高域を少し下げる EQ です（長時間聴くとき向け）。
- SHELF FREQ：2〜16 kHz（8 kHz）。この周波数あたりから上を下げます。
- SHELF GAIN：−18〜0 dB（−4 dB）。

---

## 7. 検出（基準レベル・検出の細かさ・解析範囲・Learn）

### 基準レベル
各帯域の **普段の大きさ**。突出度は「今のレベル − 基準レベル」で決まるので、基準レベルが高いほど反応しにくく、低いほど反応しやすくなります。

| 方式 | 基準レベルの決め方 | 向いている場面 |
|---|---|---|
| 固定の推定値 | 一般的な音楽のバランスを仮定した固定のカーブ（全体 −20 dB 相当、2 kHz より上は 1 オクターブごとに −3 dB、Side は 12 dB 低い） | 曲を問わず同じ基準で処理したい |
| オート（曲に追従、初期値） | 再生中の音から各帯域の普段のレベルを、約 10 秒かけて追いかける（推定値から ±18 dB の範囲内） | ふだん使い。曲の明るさに合わせて自動で調整 |
| 学習して固定 | **Learn** を押してから 8 秒間の平均を覚えて固定。プロジェクトに保存される | 曲ごとに効き方を固定したい（サビなど代表的な部分で Learn） |

- 「学習して固定」で、まだ学習していない帯域は固定の推定値を使います。
- 基準レベルの変化は、右上の **「基準レベル」表示** で確認できます（3 章）。

### Learn（8 秒）
再生しながら押すと、基準レベルが「学習して固定」に切り替わり、8 秒間で各帯域の普段のレベルを覚えます。下の状態表示が「学習中… ○○ %」→「学習済み（固定中）」になります。無音の部分は学習に使いません。

### 状態表示（Learn ボタンの下）
「オート：学習中… ○ 秒」（オート開始から 10 秒まで）／「オート：追従中」／「学習中… ○ %」／「学習済み（固定中）」／「未学習：再生しながら Learn を押してください」／「固定の推定値を使用中」。

### 検出の細かさ
- 1/3 オクターブ（初期値）：帯域が広め。自然。
- 1/6 オクターブ：帯域が細かい。狭い共鳴をピンポイントで取りたいとき。

### 解析範囲
- 1.6〜16 kHz（遅延 約 11 ms）：初期値。刺さり対策にはこれで十分。
- 400 Hz〜16 kHz（遅延 約 21 ms）：カスタムで 1.6 kHz より下（鼻にかかった声など）を扱うとき。
- 遅延は DAW に自動で伝わり、DAW が補正します（Cakewalk Sonar では再生中に切り替えても追従することを確認済み）。

## 8. おすすめの使い方

1. プリセットで近いものを選ぶ
2. 刺さる音のターゲットを選び、**Filter** で LOW / HIGH を刺さる音がよく聞こえる範囲に合わせる
3. **Normal** に戻し、PROCESSING を「刺さる瞬間だけ赤が出る」くらいまで上げる
4. **Delta** で削った成分を聴き、言葉や楽器の芯まで削れていないか確認する
5. 足りなければ INTENSITY、まだ足りなければ RANGE を上げる
6. 曲全体の明るさは残して共鳴だけ取りたいときは SELECTIVITY を上げる
7. ボーカルのさ行は「Mid」、左右に広がったシンバルは「Side」
8. 曲ごとに効き方を固定したいときは、サビなど代表的な部分を再生しながら **Learn**
9. 気に入った設定は「今の設定を保存…」で自作プリセットに

---

## 9. 保存されるもの・DAW との関係

- **プロジェクトに保存**：すべての設定（THRESHOLD、一括／帯域ごと、帯域ごとの補正を含む）、プリセット（標準なら番号、自作なら名前と内容）、学習した基準レベル、A/B の 2 組、画面の大きさ、右上の表示（スペクトラム／基準レベル）。
- **自作プリセット**：`%APPDATA%\SasariOsaeru\Presets` に保存（プロジェクトとは別）。
- **オートメーション**：DAW から自動化できるパラメータ名は英語です（例：Vocal S Processing、Mix、Range、Selectivity、Threshold、Threshold Mode）。帯域ごとの補正（Band Trim）は自動化の対象外です。
- **遅延**：約 11 ms（解析範囲 400 Hz〜 なら約 21 ms）。DAW が補正します。バイパス中も遅延は同じに保つので、タイミングはずれません。
- **音の形式**：DAW から 32 bit 浮動小数で受け取り、そのサンプルレートのまま処理して返します。
