# DeEss Tamer（Android 用ディエッサー）

Android 端末で再生される音の「サ行」の歯擦音や耳に刺さる高域だけを、大きくなった瞬間に抑えるアプリです。
操作系は Techivation T-De-Esser 2 を参考にしています（コードや音声処理は独自実装で、同製品とは無関係です）。

## 機能

女性ボーカルの「さ行」、ハイハットの刺さり、歪みギターの耳障りな高音など、**耳に刺さる音が出た瞬間だけ、その周波数だけ**を下げることを目的にしています。

### ターゲット（3種類、それぞれ個別に ON/OFF・調整）

| ターゲット | 初期の帯域 | 反応 | 狙う音 |
|---|---|---|---|
| 歪みギター | 2.5〜5 kHz | ゆっくり（アタック 4 ms / リリース 120 ms） | 持続する「ジャリジャリ」した成分 |
| さ行 | 5〜10 kHz | 速い（1 ms / 60 ms） | ボーカルの歯擦音 |
| ハイハット | 8〜16 kHz | 速い（0.7 ms / 45 ms） | シンバル類の「チッ」「シャーン」 |

各ターゲットのノブ：LOW / HIGH（帯域）、PROCESSING（反応しやすさ）、INTENSITY（下げる強さ）。
共通のノブ：SHARPNESS（ニー幅と反応速度。上記の時間を ×2〜×0.5）、MIX（全体の効き具合）、OUTPUT（出力音量）。

### ピンポイントにする仕組み

- 1.6〜16 kHz を **1/3 オクターブ × 10 本**の細い帯域に分け、帯域ごとに独立したコンプレッサーで検出・抑制します。刺さった帯域だけが下がり、隣の帯域には触れません。
- しきい値は「その帯域の普段のレベル ＋ N dB」で決めます（PROCESSING 0% = +30 dB、50% = +10 dB、100% = −10 dB）。普段のレベルは一般的な音楽の周波数バランス（ピンクノイズ＋高域で約 −3 dB/oct）からの推定値です。
- ターゲット同士の帯域が重なった部分は、反応しやすい（PROCESSING が高い）方の設定が使われます。

### その他

- Filter モニター：選択中のターゲットの帯域だけを聴く（刺さる帯域を探すため）
- 高域シェルフ（常時）、プリセット、端末起動時の自動開始、プレーヤーの「イコライザー」メニューからの起動

T-De-Esser 2 の Processing / Intensity / Sharpness / Mix / Filter モニターの考え方を引き継いでいます。

## 仕組み

Android 9 以降に標準で入っている `DynamicsProcessing` エフェクトを使っています。

```
入力 → Pre-EQ（高域シェルフ） → MBC 12バンド [〜1.6k | 1/3oct × 10 | 16k〜] → Post-EQ（Filter モニター・出力ゲイン） → 出力
```

パラメータの換算は `app/src/main/java/app/deesstamer/DspMapping.kt` にまとめてあり、JVM のユニットテストがあります。

### 適用先（どちらか一方）

- **端末全体（グローバル出力）**：オーディオセッション 0 にエフェクトを付け、全アプリの音にかけます。Android のドキュメントではこの使い方は非推奨とされていて、機種によっては付けられない・付いても効かないことがあります。
- **対応プレーヤーごと**：再生時にオーディオセッションを通知するプレーヤー（イコライザー連携に対応したアプリ）にだけかけます。このアプリより先に再生を始めていた場合は、プレーヤー側で一度停止→再生してください。プレーヤーの「イコライザー」メニューからこのアプリを選んでも有効になります。

両方に同時にかけると同じ音が二重に処理されるため、どちらか一方だけを選ぶ仕様にしています。

## インストール

1. `DeEssTamer-1.1.0.apk` を端末にコピーするか、ダウンロードします。
2. ファイルを開き、「提供元不明のアプリ」のインストールを許可してインストールします。
3. アプリを開いて右上の ON を入れます（Android 13 以降は通知の許可を求められます。許可しなくても動作はします）。

対応 OS：Android 9（API 28）以降。

## 制限

- **Diff モニターは実装していません。** `DynamicsProcessing` では処理前の音を取り出せないため、「削られた成分だけを聴く」ことができません。
- **Mix は近似です。** 本来の Mix は処理前と処理後の音を混ぜるものですが、同じ理由でリダクション量を縮める方式にしています。
- **「普段のレベル」は固定の推定値です。** 曲の音作りや端末の音量設定によって効き方が変わる可能性があります。PROCESSING で調整してください。
- **リダクションメーターはありません。** `DynamicsProcessing` は実際のゲインリダクション量を返さないためです。画面のカーブは設定値から計算した理論上の特性です。
- **オーバーサンプリングはありません**（処理は端末のエフェクトエンジン内で行われます）。
- 同じ種類のエフェクトを使う他のイコライザーアプリ（Wavelet など）とは同時に使わないでください。同じセッションに付けたエフェクトは設定を奪い合います。
- メーカー独自の音響効果や再生経路によっては効かない場合があります。
- APK はデバッグ鍵で署名しています。ビルドした環境が違う APK で上書きインストールすると署名が合わず失敗するので、その場合は一度アンインストールしてください。

## ビルド

JDK 17 以上と Android SDK（Platform 35）が必要です。

```sh
cd deesser-android
./gradlew testDebugUnitTest assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

GitHub に push すると `.github/workflows/deesser-android.yml` が APK をビルドし、Actions の成果物（Artifacts）として保存します。
